# UOMD Dotfile Policy

The following dotfiles/directories are intentionally hidden by convention and
must remain version-controlled:

- `.claude/` — Claude Code Game Studios framework, agents, skills, hooks and rules.
- `.gitignore` — Git ignore rules.
- `.gitattributes` — Git attributes.

Do not rename these merely to make them visible in a file-upload UI.
They are not disposable hidden files.

The project deliberately avoids using `.gitkeep` placeholders. Empty project
folders use visible `README.md` placeholders instead, so web upload interfaces
do not hide their existence.
