# Original free 2D demos

`upstream/` contains the original Godot VFX Library and only the official Godot sprite-shader / 2D-particle demo projects. It is local, Git-ignored and outside `game/`. Each project retains its original license. Keep the main editor/runtime open when browsing these as separate projects.

The export-excluded shader, texture and icon selections are under `game/assets/third_party/reference/`. `COLLECTION.json` there contains the exact source revisions and ZIP hashes. No plugin/autoload manager from these demos is enabled in the main game.
