# uomd-ux-review

Read [UI rules](../../standards/ui.md) and the scoped [review checklist](../../references/ux-review-checklist.md). Compare the concrete spec/runtime evidence with its source requirements, pattern library and data owners. Check states, touch/Back, English text expansion, contrast/non-color meaning, Large Text, Reduced Motion and layout. Return APPROVED / NEEDS REVISION / MAJOR REVISION NEEDED / NOT ASSESSED, with material findings and evidence limits. Spec approval does not imply runtime or owner visual approval; no new screen implementation is implied by review.

For the reviewed shared-source additions, read [touch-input guidance](references/shared-touch-input.md).
