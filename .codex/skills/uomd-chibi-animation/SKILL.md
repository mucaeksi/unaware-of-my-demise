# uomd-chibi-animation

Read [chibi standards](../../standards/chibi-animation.md) and the actual pose/atlas bindings plus identity sources. Choose the supported animation method, specify phase/event/interruption contracts and preserve stable feet, facing and full silhouette. Use uomd-godot-animation for engine details and the [animation workflow](../../workflows/animation-cutscene.md) for runtime review. Preview all requested states, interrupted/late events and Reduced Motion with local fixtures. Presentation work never changes combat math, AI or progression.
