# uomd-test-setup

Read [testing rules](../../standards/testing.md), game/tests and installed test-addon/runner documentation. Verify the actual runner and relevant command with a representative existing test when useful. Legacy gdUnit4 config is a preference, not installed evidence. Preserve current tests and strict checks; do not expand into deferred gameplay systems. Record command/version/results, distinguishing tool gaps from failures. Add a new dependency only when the owner explicitly authorizes it.
