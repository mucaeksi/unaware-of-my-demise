# Animation and cutscene workflow

Read the actual asset structure, identity/lock, binding manifest and approved timing contract. Choose key poses, frame sequences or real cutouts from evidence. Specify state timing, events, interruptions and cleanup without adding gameplay algorithms.

Compose the requested chibi/camera/VFX pass; retain stable anchors and control readability. Preview poses plus beginning/middle/end and transition/interruption states in the existing runtime. Test pause, skip/replay, reduced motion and stale callbacks as applicable. Record native evidence and measured desktop limits; preserve masters and local scope.

Use `$uomd-chibi-animation`, `$uomd-cutscene`, `$uomd-godot-animation` and `$uomd-vfx` according to the task. `.codex/standards/` contains their shared constraints.
