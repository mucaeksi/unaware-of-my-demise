# uomd-vfx

Read [VFX guidance](../../standards/vfx.md), relevant art/approval/source manifests and actual gl_compatibility settings. Inspect editor API/material/particle capabilities, then compose bounded effects with meaningful uniforms, cleanup and Reduced Motion fallback. Measure overdraw/particle/texture/frame-time costs and verify native rendering/readability. Reference-library study status is not production approval; do not import NC art or change the renderer. Keep effects tied to existing presentation events, not new game algorithms.

For the reviewed shared-source additions, read [particles guidance](references/shared-particles.md).

For CanvasItem implementation, also read uomd-godot-shaders.
