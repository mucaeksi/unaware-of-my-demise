# Gothic anime UI design
- Read canonical art direction and UI master requirements in `README.md` and `narrative/` first.
- Reference canvas is 1920×1080, but adapt to varying landscape aspect ratios, safe area, notch and low-end device pixel ratios.
- Use common tokens for aged parchment, ink, antique gold, violet-black, typography, borders, focus, disabled states and interaction timing.
- Prepare touch-first navigation for story, roster, summon, team, inventory, settings, shop and boss screens.
- UI/UX Pro Max is a reference tool; never imitate unrelated SaaS layouts on the game client. Admin panel may use React components.
- Verify state accessibility, text scaling, localization overflow, keyboard navigation, touch targets and loading/error/empty states.
- Test at real mobile viewport sizes and visually compare screenshots, not only the 1080p reference.
