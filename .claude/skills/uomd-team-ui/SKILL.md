# uomd-team-ui

Follow the [Entry UI workflow](../../workflows/entry-ui.md). Use uomd-ux-design/review for requested spec work, art bible and UI standards for visual direction, then current Godot architecture for implementation. Only when delegation is authorized, use the functional art-director, ui-engineer, technical-artist and qa-reviewer custom agents; otherwise perform the workflow directly. Share a concrete scope, source paths, destination ownership and expected evidence with each permitted agent. Integrate coherent results, resolve technical conflicts with evidence, and refresh the same sample-data native preview after validated phases. Do not auto-advance to the next screen.
