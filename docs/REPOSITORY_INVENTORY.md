# Repository inventory

Current navigation inventory: 2026-10-08. The machine-readable catalogue is generated by `tools/project_catalog.py build` into ignored `.local/project-index.json`. Its summary gives measured authored-file counts, bytes and category counts. Runtime selection is independently recorded in `release/current/FILE_INDEX.json`.

| Folder | Role | Editable/generated |
|---|---|---|
| `game/` | Active Godot source, tests and selected runtime assets | Editable source |
| `server/`, `admin/`, `database/` | Online services, admin and migrations | Editable source; outside opening snapshot |
| `narrative/` | Canon, approved references, creative source and VO history | Preserve source and read-only originals |
| `docs/` | Current design, decisions, UX, implementation evidence | Editable documents; dated history retained |
| `.codex/` | Active agent/skill/standard/workflow system | Active tooling |
| `.agents/library/` | Consolidated provenance and deferred capability index | Active index |
| `.agents/skills/` | Discovery links to `.codex/skills/` | Linked; no duplicate skill copies |
| `.agents/archive/`, `.claude/`, `.archive/` | Historical instructions and preserved documents | Historical; not active authority |
| `tools/` | Export, validation, cataloguing and graph helpers | Editable tooling |
| `references/`, `game/assets/third_party/reference/` | Licensed upstream collections | Local/reference; excluded until selected |
| `production/` and external Production/LEGACY | Earlier production checkpoints/originals | Read-only |
| `release/current/` | One verified test source/artifact version | Generated; upstream edits only |
| `build/`, `.local/`, `graphify-out/`, `local-backups/` | Build evidence, indexes, graph and backups | Generated/private; excluded from publication |

`game/tests/`, tutorial data, creative files and workflows exist. Claims of their absence in the 2026-10-03 inventory are historical; that original is preserved in `.archive/project-docs-20261008/`.

Use [Project map](PROJECT_MAP.md) for feature-to-file navigation and `python tools/project_catalog.py find <words>` for exact paths. Asset measurements and duplicate/hash evidence from the current audit are in `build/project-organization-20261008/ASSET_AUDIT.md`. Duplicate source variants are preserved; a matching hash alone does not authorize deleting canon or reference files.
