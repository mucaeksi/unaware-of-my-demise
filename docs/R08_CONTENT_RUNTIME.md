# R08 runtime and delivery contract

This describes the implemented data boundary. Evidence belongs in DEV_TRACKER.json; a local browser run does not establish deployed or signed Android acceptance. R09 owns the complete Continue/resume journey; R16 owns production Japanese performance and final balance; R18 owns physical WebView and Play acceptance.

## One effective release

Publication of new capabilities first probes the bound game Worker for the same environment/channel, protocol support and migration 0027, with a three-second deadline. An old/unavailable/misbound backend leaves the draft unsigned; rollback uses the same gate and emergency kill remains available. Game and admin deploys can finish in either order. Local dev and staging use the existing GAME service-binding pattern.

A published release is a complete signed snapshot, including `catalog/economy.json` when using versioned economics. Both the game and API select that release. Authoring tables supply exports and future drafts; they are not a fallback for declared but missing/corrupt snapshot data. Player ownership, levels, instances, rolls, wallets and progress remain in D1. Immutable ID registries preserve references without materializing definition rows.

New signup uses current published free-start definitions in the account transaction. Existing login needs no catalog reload. Fresh team, growth, gear, summon and task operations select the installed release and join the existing active-account/economic guard in the final transaction. Current/allowlisted/frozen-battle grace, revocation and kill-floor rules remain authoritative. Exact recorded results recover before current release/catalog admission.

Migration 0027 freezes one task rule set per player/UTC week, including daily cadence, weekly windows, targets, payouts and referenced grant definitions. First observation wins atomically. Later authoring/publication changes apply to that player's next week. Old weekly terms remain claimable only through their original bounded grace; no new historical week is invented. Migration backfills legacy task weeks with migration-time legacy config, explicitly without reconstructing unknown historical terms. Claims remain unique by player/period/task across releases.

Earned mail and provider-bound purchase fulfillment store the referenced grant definitions when terms are first frozen. Retry/restore, subscription instant grants and periodic mail honor those definitions after catalog changes or R2 loss. Existing legacy records retain their explicit legacy contract. Paid receipt recovery remains available even if an offer is removed or outside its discovery calendar. Native pre-purchase price/benefit binding remains R02; schedules never revoke verified payments.

Missing/retired owned characters remain in inventory and receive an unavailable explanation. Missing equipment remains visible with its real instance state, without fabricated playable stats; unequip and lock/unlock remain available under the selected authority. New equip/growth/summon/battle requests cannot use an absent definition. No implicit conversion, deletion or compensation is performed.

## Closed grammar

Every `.json` path must match an implemented schema. Unknown JSON, operations, properties, references and malformed UTF-8 fail admission, including unlinked story and encounter files. `release.json` is transport metadata, excluded from content file sets. Plain text is inert; patches cannot contain JS, HTML, SVG, WASM, shaders, expressions, remote URLs, property paths or downloaded callbacks.

| Path/kind | Interpreter and references |
| --- | --- |
| `units/unit_pack.json`, `art/art_manifest.json` | Existing finite combat/effect grammar; bounded atlas frames, portraits/emotions, backgrounds, music and optional frame animations. Frames must exist and lie inside declared atlas bounds. |
| `chapters/chapter_index.json`, `story/*.json`, `encounters/*.json` | Compiled chapter/reward/drop graph, stable lines, choices/labels, finite boolean flags/branches, waits and checkpoints. Nonblocking control loops have a finite step budget. |
| `entry/entry_index.json` and its prologue | Authored plates/timings/English lines; optional whole-opening video covers the authored duration and carries no Skip control. |
| `library/library_index.json` | Stable companion/codex/event IDs and existing ownership/progress/order gates. |
| `catalog/economy.json` | Closed character/skill/item/gear/set/type/banner/progression/drop/task definitions and exact pack/chapter references. |
| `presentation/presentation.json` | JA voice map keyed by stable English line IDs; typed audio cues; WebM clips with ordered English subtitle cues; locale declarations; fixed notices with compiled actions. Media paths must exist. Recorded JA declarations require reviewed-transcript SHA-256 provenance; that field is provenance, not a speech-quality measurement. |
| `locales/<declared-locale>.json` | Bounded strings for known story/prologue/notice text IDs, with English fallback. Settings select the locale; story, captions and notice reader consume it. Translation of all compiled UI belongs to R10. |
| `schedules/events.json` | Absolute UTC start-inclusive/end-exclusive event discovery/read/completion windows; completed entries remain replayable in Archive. Server time and existing gates apply. |
| `schedules/shop.json` | Absolute UTC offer discovery windows over existing product IDs. Receipts and earned obligations remain fulfillable. |
| Catalog banner/task schedules | Existing banner start/end and finite UTC daily/weekly mission cadence are executed by their respective authoritative services; weekly task terms are frozen as above. |

The owned narrative stage implements voice, play/stop sound cues, video, still/UI layers, bounded tween fields/eases, stage camera transforms, rectangle/ellipse masks, removal and notice commands. HUD controls are outside stage camera transforms. A maximum of 16 layers, two WebGL mask filters and eight audio cues can be alive simultaneously. Fixed notices have at most eight body pages/four actions, validated illustrations and optional server-gated node/calendar windows. Actions select only compiled screens, admitted notices or Close; a modal returns to its paused story.

Voice has independent volume and replay; English/localized text remains readable after playback rejection. Video uses verified local URLs, timed captions, explicit Play/Pause, optional authored Skip, dialog focus trapping and background/scene pause. Invalid metadata, codec errors or sustained active playback stalls present the authored caption transcript and Continue. Closing a scene removes its media, listeners, ducking, layers and modal children. Notice body text is paged after wrapping; decoder-fallback transcripts scroll and participate in dialog focus. A source checkpoint stores one bounded local runner snapshot; it does not constitute account/release-scoped R09 resume acceptance.

## Binary and trust boundary

Client **0.1.2** is required for catalog activation and the new presentation/locale/animation/flag primitives. Publisher and offline builder derive signed `required_capabilities` (including calendar-only releases) and retain explicitly stricter source/offline requirements; composition unions source requirements and intersects min/max/schema limits. Publish refuses an old draft missing its required declaration. Rollback retains source requirements and tightens the binary minimum as needed; it never widens maximum/schema/capability requirements. Emergency kill preserves the source compatibility declaration so compatible legacy binaries can still be disabled.

Trust roots are **compiled public P-256 keys**, with 1–8 unique bounded IDs and no private scalar. There is no downloaded root/intermediate delegation. Rotation to a second root already present in the installed binary can use that root's signing key without another AAB. Adding/replacing/removing a root, revoking a compromised root on installed clients, adding a primitive or changing these compiled limits requires a new reviewed AAB with an explicit versionCode. Unknown or duplicate key IDs and signatures from other keys are rejected. Previous strict binaries can reject the extended manifest as malformed before their minimum-version check; that still prevents object downloads. Current-parser mixed-version tests do not substitute for the old-AAB/store-update UX check in R18. A signed content file cannot install its own trust root. Kill/revocation protects online economics; it cannot remotely erase a compiled offline trust key. Never claim otherwise.

## Storage, transport and resource bounds

| Resource | Contract |
| --- | --- |
| Release | At most 512 paths, 25 MiB/object, 200 MiB signed total. Deduplicated metadata queries use at most 100 D1 parameters. |
| JSON | At most 1 MiB/document and 8 MiB/release, checked before Worker reads/parse. Publication checks actual JSON hashes and media presence/size, not just stale upload-index rows. |
| Worker | Validation retains bounded JSON and media-presence markers; it does not buffer the full media season. At most one GET or HEAD per effective path per validation. Current official Workers limits (retrieved 2026-10-14): 128 MB isolate memory, six simultaneous outgoing connections, paid default 10,000 subrequests; Free has 50 general/1,000 internal subrequests. Full-season publication is a paid-plan workload, not a Free-plan capacity promise. CPU/peak memory on a deployed season still require R17/R18 measurement. See https://developers.cloudflare.com/workers/platform/limits/. |
| IndexedDB | Version 2 migrates existing objects' byte accounting without rewriting player data or generation marks. Object/size/prefix promotion and state/mark/reservations/GC use atomic transactions. Success resolves on transaction completion; abort/quota failures reject. Blocked/unavailable IDB falls back to memory with a visible notice and cannot promise a staged patch survives restart. Late refused opens close their eventual connections. |
| Retention | The 200 MiB device budget includes actual active, previous, staged, partial and reserved bytes, deduplicated by object hash. Atomic expiring leases protect competing downloads/GC. GC deletes orphans only against an unchanged pointer snapshot and retains live reservations. A full healthy previous release is retained even if a candidate is rejected for space. |
| Device quota | Browser usage/quota headroom is checked when available, with 20% transfer slack and 8 MiB reserve. Estimates are advisory; actual QuotaExceeded still fails safely. No account progress is stored in the patch cache. Loss/corruption rolls back to healthy content/base, preserves surviving generation authority and displays a reconnect/storage notice. Complete browser storage deletion can erase local marks; server economic admission remains required. |
| Transfer | A 90-second total deadline, linked AbortSignal, bounded retries and abortable backoff. Explicit session consent is required on detected cellular/data-saving connections. User cancellation cannot activate late work. Returning startup attempts a bounded four-second update before building its art library; slow/failed work resumes as a staged background download with a visible explicit restart action. It never changes a running scene's art implicitly. Immutable objects support strict open-ended Range requests and exact Content-Range checks; an ignored Range restarts at zero. Prefixes checkpoint at 1 MiB intervals and are never trusted until complete size/SHA-256 verification. Bad full cache objects are rejected/removed; retry downloads clean bytes. |
| Runtime cache | JSON LRU: 64 entries/8 MiB. Media: 128 MiB managed asset cost, full hash keys, preactivation image-header admission and runtime atlas checks, maximum 4096×4096/16M pixels. Music is bounded to 180 authored seconds, stereo/≤96 kHz with decoded-buffer accounting. Owners pin shared texture/audio/Blob resources through scene/playback shutdown; last release destroys the resource and revokes Blob URLs. |

The managed cache budget excludes engine framebuffers, text textures, browser HTTP cache and codec implementation overhead. Those require actual device memory/FPS/long-session measurement; software WebGL screenshots cannot establish that result. The fixed binary limits deliberately reject an oversized season rather than silently discarding a healthy rollback target. Authors must split/reduce media or ship a reviewed binary when the envelope is insufficient.

## Verification boundaries

API tests use actual local D1/R2 and public draft/publish signing. Browser acceptance builds once per disposable stack, publishes a synthetic new identity and media package through the real API, then installs it into the same built browser binary. The fixture clones existing numeric definitions and reuses art; its tone/test-pattern clip tests transport/decoding only. It is not new canon, Japanese speech quality, approved production media, native unchanged-AAB proof or a balance playthrough.

Run the full workspace/tool suite, lint, types, campaign/build/adapter checks and desktop/touch-phone cases before delivery. R18 must repeat signed patch interruption/range/cancel/quota/eviction/background/decoder/resource/rollback cases on physical WebView, recording AAB hash/versionCode, device/WebView, release generation and deployed Worker version. No device result may be inferred from local tests.
