# CODER RESPONSE FORMAT

After each major phase, report in this exact structure.

## PHASE
Name + status

## WHAT I DISCOVERED
Concrete facts only.

## WHAT I CHANGED
Exact files/systems changed.

## WHAT I VERIFIED
Tests, imports, builds, runtime checks.

## WHAT REMAINS
Known incomplete items.

## BLOCKERS
Only real blockers.

## DECISIONS REQUIRED
Only questions that genuinely require human authority.

## NEXT APPROVED STEP
One clearly bounded next step.

Never report a feature as complete solely because code was written.
