   `unaware-of-my-demise-admin`, Hyperdrive `unaware-of-my-demise-production` → Neon PostgreSQL, R2
   `unaware-of-my-demise-content`/`uomd-db-backups`. The README forbids a competing database, so a decommission plan
   (data export, then removal) needs the owner's approval. **Untouched by this work.**

   (flagged in the narrative audit as VIS-04). The slice uses the approved runtime sheets; owner should pick one.
3. Hollow Pilgrim/Bellbound are not chibi (realistic skeletons) – consistent with the old approved runtime art only.
4. Combat numbers are on the "compact scale" (HP 11–14); balance is `draft_v1_needs_battle_simulation`.
5. Context7 hosted MCP is rate-limited without an API key (see `SKILLS_MCP_STATUS.md`).
6. Two Vite majors coexist (apps pin 7.3.7; Vitest 4 brings 8.x). Harmless, tracked in `DECISIONS.md`.
