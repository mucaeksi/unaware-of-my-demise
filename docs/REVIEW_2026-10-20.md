## 2. Skeleton map

**Client (`apps/game`, PixiJS v8 + HTML/ARIA layer), 26 scenes.** Boot → Splash (PixiJS credit) → Studio → Title (Continue / Chapters / Company / Settings / Replay intro) → Prologue (9 shots) → Story ↔ Battle (T-1..T-3) → Finish → restart. After entry: Chapters (stages, Sweep), Home hub (Summon, Roster, Team, Errands, Armory, Mail, Shop, Account, Actions, Notices, Archive), Character, Gear, Recruit, Purchases, Operations, Library, ContentPanel, PatchBar.

**Server (`apps/api`, Workers + D1), 89 public routes.** Auth/account/privacy/save/entry, progress (story, battle start/verify with frozen server parties, sweep), characters/gear/teams/recruitment, gacha/banners/shop/billing/ads/wallet/mail/tasks/supplies, modes (AFK, achievements, events, profile, leaderboard, arena, endless), content/catalog/presentation/library/flags/health.

**Content pipeline.** Narrative runtime snapshot (`narrative/09_VN_Scripts/Runtime_Snapshot`) → `tools/build_content.ts` (base release) and `tools/build_campaign.ts` (Part I patch + balance probe) → signed releases; D1 seeds from `tools/seed_characters.ts` / `tools/seed_catalog.ts`; stats from `content/balance/attributes.json` and `tools/lib/balance.ts` (D-27).

**Mechanics.** `@uomd/combat`: deterministic 5v5 gauge turn order (SPD), Focus/ultimates, 15 statuses, 25+ ops, bosses with fresh-bar phases/objectives/telegraphs/summons, multi-wave support, Auto policy, replay hash. `@uomd/economy`: D-27 attributes (`deriveStats`), progression (level/ascension/skill ranks/gear levels+milestones), gacha/pity, drops, Ration (100 cap, +1/5 min), tasks, chronological simulator.

## 4. Recommended path

1. **Stabilise staging** (#1) — done when `/api/v1/characters` returns 200 on the redeployed tag.
2. **Close the core loop:** pace probe (#3, done) → owner target → XP/AFK/material tuning → the six missing mode screens (#2). This turns "the server can" into "the player can", with a measured pace for "level 20 is hard to reach".
3. **Owner decisions that unblock content:** target pace (#3), combat semantics list (#7), economy tuning (#6), signature weapon effects (#5, with Argon).
4. **Content fixes by Argon:** missing banners (#4), signature effect designs (#5), then the art pilot through `tools/ingest_art.ts`.
5. **Debt:** waves in the builder (#8), paged screens (#9), phone/tablet e2e and device runs.

Why this order: the skeleton is broad and mostly sound; what is missing is the client surface for half of the progression systems and the numbers that tie them together. Visual work does not depend on either, so Argon can continue assets in parallel.
