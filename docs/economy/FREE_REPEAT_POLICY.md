# Free campaign practice and reward eligibility

Applied under the owner’s autonomous infrastructure assignment; scope is the repeat-mint defect, with final numerical balancing left to R16.

The compiled `stage_1_1` uses the zero-cost tutorial Ration class but references a general repeat drop table. The existing `NodeRewards` contract says repeat rewards belong to Ration-paid wins. The previous service ignored that eligibility and paid each fresh request ID. Rate limits only slowed unlimited minting.

The server now pays `repeat` attachments and repeat drop-table entries only when the verified node actually spends Ration. Free wins retain configured first-clear and first-three-star rewards, including first-clear drop entries; subsequent practice can update progression without producing repeat currency, materials, gear or XP. The first free win also receives no repeat portion. Paid stages retain their configured repeat tables and amounts. No narrative files, rates, prices, first-clear/three-star amounts, historical balances or previous claims are rewritten.

Every retry returns the original recorded result and eligibility, including pre-upgrade records whose new eligibility field is absent. Concurrent first clears converge through the existing transaction guards. Source/canon mismatch is recorded here; R07/R08 must validate/communicate effective reward eligibility when compiling/publishing catalogs. A future capped free-repeat economy would be a deliberate data/policy change, not a request-ID or throttle workaround.

Evidence: real compiled stage_1_1 with a known deterministic winning action list, repeated fresh IDs and twelve concurrent claims (both cases failed before correction); a free fixed-reward fixture verifies finite first/three-star amounts and response-loss replay. Existing paid-drop cases still pass. Chapters and victory feedback disclose free practice; actual desktop/phone browser checks and the desktop campaign scenario cover the affected flow. This is local source evidence, not proof of deployment/native acceptance or final economy viability.
