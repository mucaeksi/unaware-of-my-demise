# Runtime içerik kopyası

Bu klasör otomatik, byte eşit bir inceleme kopyasıdır. Düzenlemeyin.

Asıl yükleme yolları `game/data/content`, `game/data/entry` ve `game/data/stable_ids.lock.json` olarak korunur.

Yenileme: `python tools/collect_narrative.py`; kontrol: `python tools/collect_narrative.py --check`.

Kopya, ilk AAB'nin bütün bu içeriği içerdiği anlamına gelmez; AAB/patch sınırı ayrı export yapılandırmasıdır.
