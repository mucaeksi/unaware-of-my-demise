# Özgün senaryo JSON kaynakları

- [Main_Story](Main_Story): yedi bölümün özgün authored sahne/replik kayıtları. Ana akış sırası [manifestte](../02_Main_Story/story_script_part1_manifest.json) tanımlıdır.
- [Companion_Stories](Companion_Stories): karakter yan hikâyeleri; açılma koşullarıyla birlikte kullanılır.
- [Events](Events): mevcut event senaryoları.
- [Voice_Lines](Voice_Lines): karakter tetikleyici/ilişki ses replikleri ve açılma koşulları.
- [Runtime_Snapshot](Runtime_Snapshot/README.md): oyunun mevcut verilerinin otomatik inceleme kopyası; yazarlık kaynağı değildir.

İnsan tarafından okunacak ana giriş [Narrative README](../README.md). Ana hikâye, yan hikâye, event ve VO okuma sürümleri bu JSON'lardan üretilir. Eski `PART1_FULL_SCRIPT.md` kopyaları kaynak değildir.

`02_Main_Story/Chapters`, `03_Companion_Stories/character_stories_part1.json` ve `04_Events/events_part1.json` önceki aktarım kopyalarını korur. Fark görülürse sessizce tek sürüme çevirmeyin; canon kararını ve kaynak geçmişini inceleyin.
