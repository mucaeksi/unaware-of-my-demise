# Music Prompts — Part I (Lyria, 2026-09-30)

Every track except the main theme (the owner handles `bgm_main_theme`). Model `lyria-3.5` (WAV) for every track and stinger (C44: one model per medium; stingers are trimmed from a short generation). Generated by `tools/gen_audio.py music`.

**Leitmotifs are not left to Lyria.** Fadyme's theme and the Ledger motif are composed as MIDI by the Narrative & Visual Director (`audio/music/motifs/`) and placed over or before the Lyria beds, so the same melody returns everywhere. Bed prompts give the motif's key, tempo and metre.

**Waves:** 0 = reference set, owner approves (Fadyme theme bed + motif, ch1 forest in three layers, standard battle). 1 = everything else, approved by the Director against the reference set.

**Rules in every prompt:** instrumental (wordless choir only where stated), no artist or game names, no drums unless stated, loopable ending, clean mix.
