# Character Models

One file per playable character (stable IDs from `content/characters_part1.json`). Facts marked **[NEW]** were added in the Phase 3 director pass (2026-09-27) and do not contradict any script line; everything else is already in the scripts, GDD or lore files.

Tiers: **A** carries the main story · **B** carries a main mystery · **C** deepens through a four-part companion story.
Companion stories follow one rule: each shows something the main story cannot. They never retell main chapters.

See `_voice_matrix.md` for the differentiation of speech across the roster.
