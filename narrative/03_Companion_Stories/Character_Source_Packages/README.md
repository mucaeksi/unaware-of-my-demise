# Karakter kaynakları

[Karakter indeksi](INDEX.md), mevcut 20 oynanabilir karakterin runtime
tanımlarına, görsel brieflerine, karakter hikâyelerine ve ses repliği
kataloglarına erişim sağlar.

Özgün Legacy karakter/lore belgeleri Drive'dan doğrulandıktan sonra,
mevcut stable ID'lerle karakter paketlerine bağlanır. Henüz indirilmemiş
belgelerden yeni canon, tasarım veya onay durumu üretilmez.
Aktarım durumu: [Legacy Narrative kaydı](../migration/README.md).

Fadyme'nin onaylı görsel/ses referansları
[kilitli referans paketindedir](../references/fadyme/README.md).
