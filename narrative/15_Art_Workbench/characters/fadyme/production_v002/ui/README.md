# UI source handoff

The four existing modern-style exports are retained unchanged under their actual v001 versions: MenuAvatar 256², BattleHUD 512², Roster 512², CompanionCard 768×1024. They match the supplied current face/costume; these are staged reusable sources, not newly generated images. Default UI never exposes blood, white-lock or black-gold hand story states. Candidate skill icons and weapon/prop artwork are separate. No runtime path is promoted by this package.
