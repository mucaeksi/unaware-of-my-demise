# uomd-screen-presentation

Current implementation scope is Entry. For an explicitly requested future-screen plan, read [UI rules](../../standards/ui.md), source screen/character requirements and [chibi](../../standards/chibi-animation.md)/[VFX](../../standards/vfx.md) standards. Plan entrances, reveal/cut-in/hold/exit, skippability, duplicate input, loading/error/offline and Reduced Motion using local sample or already confirmed payloads. A visual summon reveal never selects a character, computes rates/pity/currency or grants rewards. Preserve the current router/authoritative transaction contract. Implement another screen only after the owner selects it; preserve deferred systems without developing them.
