# uomd-perf-profile

Read [Godot runtime rules](../../standards/godot-development.md) and the scoped implementation/source budgets. Capture no-screenshot frame-time distribution, draw/particle/texture/memory observations and cleanup across enter/exit/replay where relevant. State fixture/runtime/device, sample duration and measurement limits; unknown budgets stay unknown. Separate capture overhead and desktop Compatibility results from Android release acceptance. Recommend or implement only task-authorized changes supported by measurements, then compare affected behavior.

For the reviewed shared-source additions, read [android-performance guidance](references/shared-android-performance.md).
