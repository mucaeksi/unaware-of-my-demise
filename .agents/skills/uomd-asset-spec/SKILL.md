# uomd-asset-spec

Read [art bible](../../standards/art-bible.md), [pipeline](../../standards/asset-pipeline.md) and the requested target's actual source/spec. Inventory required/shared assets and existing IDs before drafting. Use [asset fields](../../references/asset-spec-fields.md), including framing, dimensions, palette/light, transparency, anchors, status and provenance. Image prompts reference approved identities/style, composition and exclusions; audio entries describe cues/direction. Keep existing IDs/blocks on reruns and append new entries using the real registry convention. Flag missing canon or technical budgets instead of inventing them.
