# uomd-ux-design

Read [UI rules](../../standards/ui.md), current screen requirements, relevant architecture decisions and existing spec. Choose a [screen spec](../../references/templates/ux-spec.md), [HUD](../../references/templates/hud-design.md) or [patterns](../../references/templates/interaction-pattern-library.md) only when needed. Cover arrival/navigation, layout/state inventory, touch/Back, source/null/update behavior, events, transitions, English copy expansion, Large Text and Reduced Motion. Preserve completed sections; write testable criteria proportional to the request. Stay on Entry unless the owner selects another screen.
