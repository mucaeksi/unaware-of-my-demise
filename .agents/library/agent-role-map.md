# Functional agent selection

The 40 historical Markdown roles remain knowledge cards in `roles/` with exact
sources in the archive. Six narrow, real Codex custom agents replace the roles
needed for the owner's current 2D presentation priorities:

| Active TOML agent | Historical responsibilities consolidated | Boundary |
|---|---|---|
| art-director | art-director, visual aspects of creative-director and ux-designer | Visual standards/specs; no new canon or gameplay |
| ui-engineer | ui-programmer, Godot UI/language aspects of godot-specialist and godot-gdscript-specialist | Existing UI architecture and requested screen |
| animation-artist | 2D motion/cinematic parts of technical-artist, gameplay-programmer and narrative presentation roles | Presentation timing/assets; no combat algorithms or story invention |
| technical-artist | technical-artist, godot-shader-specialist, rendering parts of performance-analyst | Shaders/particles and measured renderer costs |
| asset-pipeline-specialist | asset-pipeline-manager, art tooling responsibilities | IDs, provenance, licenses and authorized local promotion |
| qa-reviewer | qa-lead, qa-tester, accessibility-specialist, review parts of lead-programmer | Concrete scope/evidence; no game implementation |

All other responsibilities remain deferred, including economy/AI/progression,
network/live operations, publishing, community and broad production planning.
These are responsibility mappings, not additional callable agents. Custom agents
inherit the owner's model, effort, permissions and MCP/plugin configuration.
